# Фотографии

## hero.jpg — фон первого экрана

Положите сюда файл с именем **hero.jpg** — он сразу встанет фоном главной.
Пока файла нет, показывается градиент-заглушка, вёрстка не ломается.

Требования:
- ширина от 2400 px (экраны с высокой плотностью пикселей);
- вес после сжатия до 400 КБ, иначе мобильный трафик из Азии будет ждать;
- формат jpg или webp; webp при том же качестве весит вдвое меньше.

Точка кадрирования задана в `globals.css`, класс `.hero-photo`,
свойство `background-position: center 58%` — сдвиньте процент, если
центр композиции окажется не там.
